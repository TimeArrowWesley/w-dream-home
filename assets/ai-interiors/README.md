# 全屋 AI 成品視角

2026-09-15 更新。V1～V4 每版 12 空間、每區 3 方向，共 144 個視角。

`catalog.js` 對應目前模型生成的全屋圖集，含原始模型圖、AI 大圖及縮圖路徑。圖檔位於 `成品圖集/20260914暗色現代工業/`，由根目錄 `AI寫實視角.html` 瀏覽。
